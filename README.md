# Proyecto-de-ahorcado
Contexto 
He desarrollado este código para un juego de ahorcado por diversas razones que van más allá de simplemente programar. En primer lugar, quiero mejorar mis habilidades de programación en Python, centrándome en conceptos como funciones, el uso de ciclos for  y while también usando listas y matrices. Este proyecto me ayudo a practicar mi lógica de programación y se me dio una gran experiencia que combina diversión y aprendizaje.
Además de esto yo elegí el juego del ahorcado por que creo que es un juego muy dinámico y ayuda a desarrollar de una manera muy entretenida la ortografía y el vocabulario. Al implementar este código, quería crear una herramienta que hiciera que el aprendizaje fuera más atractivo.

Como usar el código y cómo funciona 
El código funciona de la siguiente forma se inicia en Python y te solicitara las siguientes opciones 1”jugar”  ,   2”funcion”  ,  3”Salir” si selecciones el jugar la función llamara la palabra secreta que la tendrás que adivinar tecleando una letra el juego solo te dejara 6 errores si te gastas todos tus intentos el código y no completaste la palabra el código dará por finalizado el juego y te dará un mensaje el cual será que perdiste pero si logras completar la palabra antes de que gastes tus intentos el juego te dará por el ganador y finalizara el juego
